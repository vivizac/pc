# 올리 학원별 통합 상담예약 — 4단계 개발 기록 (2026-10-26)

**핵심 결정 변경:** 알림톡 승인 템플릿에서는 학생별 개인 링크를 사용할 수 없으므로 학원마다 하나의 고정 예약 URL을 발급한다. 학부모는 해당 URL로 들어와 학생 이름과 비비작 채널 알림톡을 받는 보호자 휴대전화번호만 입력한다. 나이/학년 입력은 제거한다. 일부 부모님이 만나이로 적는 상황도 고려했다.

## 보안·매칭
- olli_booking_public_academies: 원장 계정에서 생성·재조회하는 학원별 영구 난수 식별자. URL은 학원별 동일하며 학생 ID를 담지 않는다.
- 학부모 입력의 이름(공백 제거)과 전화번호(숫자만 비교)는 해당 학원의 현재 재원생과 활성·확인된 보호자 연락처에 일치해야 한다. 학생이 **정확히 한 명** 조회될 때만 SMS 인증 절차가 열린다.
- 동명이인, 중복 연락처, 휴원·퇴원·삭제 학생, 미등록 번호, 다른 학원 학생은 자동 연결 금지.
- 이름과 전화번호만으로 예약/열람 권한을 주지 않는다. **6자리 문자 인증번호(5분 유효, 최대 5회 시도)** 확인 후, 기존 보호자 전용 RPC에 제한된 **45분 임시 세션**을 부여한다.
- SMS 발송을 위한 번호는 보호된 서버 RPC에만 노출하며 외부 요청 응답은 일관된 수락 메시지만 제공한다. 세션 토큰과 학생 ID는 고정 예약 URL이나 알림톡 템플릿에 포함되지 않는다.
- 보안 강화: 학원·IP 시간당 요청 제한, 학생별 인증 시도 간격 제한, 해시로 OTP 보관, 취소·변경은 기존 제한 적용.
