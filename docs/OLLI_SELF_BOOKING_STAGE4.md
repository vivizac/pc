# 올리 학원별 통합 상담예약 — 새 사용자 흐름 (2026-10-26)

## 학부모 화면
- 학원별 영구 URL 접속 즉시 상담 달력과 예약 가능한 날짜/시간 표시. 초기 학생 확인 화면 없음.
- 날짜·시간을 선택한 후 화면 아래에서 학생 이름과 카카오 알림톡을 받는 보호자 전화번호 입력.
- **상담 예약하기** 클릭 시에만 서버에서 등록 학생 이름+전화번호를 정확히 매칭하고, 성공하면 그 자리에서 예약 저장.
- 올바르지 않은 이름, 전화번호, 중복된 학생+전화번호는 **“학생 이름 또는 보호자 휴대전화번호가 올바르지 않습니다. 다시 입력해 주세요.”** 안내. 다른 후보 학생 정보 미노출.
- 문자 인증번호, 인증번호 입력창, 인증번호 SMS 발송 모두 없음. 나이/학년 입력 없음.
- 이미 예약된 학생은 같은 버튼으로 기존 예약 확인. 예약 변경 및 취소는 성공한 매칭 후 발급된 45분짜리 세션에서만 가능하며 URL과 브라우저 저장소에는 보관되지 않음.

## 서버
- `olli_booking_public_slots`: 학생 인증 없이 학원 식별자와 날짜로 빈 시간만 조회. 학원별 예약 설정을 사용.
- `olli_booking_public_reserve`: 이름+보호자 번호 정확히 **1명** 일치, 현재 재원생, 활성·확인된 알림톡 연락처, 학원 식별자 일치 시에만 DB 트랜잭션 안에서 예약. 중복 및 시간 충돌은 기존 DB 제약·원자적 RPC로 제어.
- 허위 조회 남용 방지를 위한 IP/학원별 시간당 제한을 유지하고 서비스 키는 서버에만 보관.
- 이름과 전화번호를 아는 제3자가 예약·변경·취소할 위험은 문자 인증을 제거했기 때문에 남아 있음. 사용자가 선택한 간소화 방식이며 보안상 한계에 주의.
- 알림톡 자동 발송과 실제 Solapi 연결은 이번 단계 범위에서 제외.

## 상태
