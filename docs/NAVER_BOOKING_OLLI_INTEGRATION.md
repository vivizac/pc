# 네이버 예약 → 올리 상담 관리 연동 / 1단계

작성: 2026-10-24. **개발 브랜치 작업이며 운영 DB와 앱은 변경하지 않았다.**

## 실제 확인된 사항

- 네이버 예약 확정 알림 메일: 학원명, 예약번호, 예약 상품, 예약 신청일, 이용 일시, 일부 가려진 예약자 이름, 예약 상세 링크.
- 메일 본문에 학생 이름이나 학년·나이 답변은 없다.
- 로그인한 네이버 파트너센터 예약 상세 우측 패널의 **예약자입력정보**에는 **이름** 및 **(초등, 유치부 반) 학년 또는 나이** 값이 실제 표시된다.
- 공개된 네이버 개발자 API 문서에서 모든 사업자가 이용 가능한 예약 상세 조회 API는 확인되지 않았다. 브라우저에서 한 번 성공한 읽기를 서버 자동화 권한으로 오해하지 말아야 한다.

## 이번 코드 범위

- 확정 이메일만 엄격하게 인식하는 순수 파서: packages/common/api/_lib/naver-booking-mail.cjs
- 미지의 취소·변경 이메일은 승인되지 않은 형식으로 처리한다. 확정 기록을 잘못 덮어쓰지 않는다.
- 학원 이름이 있는 예약 메일은 학원 이름을 대조한다. 이름이 없는 형식은 **사전에 해당 학원에 등록·인증된 네이버 예약 서비스 ID**(예약 상세 URL의 `/bizes/{ID}/`)와 일치하는 경우에만 받아들인다.
- 같은 Gmail을 여러 학원이 사용하더라도 올리의 학원 ID별로 확인된 서비스 ID를 매핑하고, 이름·서비스 ID가 충돌하면 수신을 보류한다. 한 메일 주소만으로 학원을 추측하거나 고르지 않는다.
- 이 파서는 메일 본문의 발신 주소 문자열을 검사하지만, 그것만으로 실제 네이버 발송을 증명할 수 없다. 운영 Gmail 연동 계층에서 Gmail이 제공하는 메일 인증 정보와 연결된 계정 권한도 확인해야 한다.
- 외부에서 받은 발신자 표시, 예약번호, 이용 시간 및 예약 상세 링크의 예약번호·서비스 ID 일치를 검증한다.
- 예약자 마스킹 이름은 학생 신원으로 사용하지 않는다. 상세 질문을 조회하기 전에는 학생 연결값을 비워 둔다.
- 수신 메일은 자동으로 읽지 않으며, 이번 단계에는 Supabase 변경, 예약 생성, 자동 실행, UI 반영이 없다.

## 후속 개발에 필요한 검증

1. **Gmail 운영 연동**: 학원별 OAuth 승인 또는 소유자가 직접 승인한 전달 경로. ChatGPT에서 연결한 Gmail과 올리 운영 서버 권한은 별개. 예약 메일은 인증된 Gmail API로 발신자/학원 범위를 확인한다.
2. **운영 저장소**: 학원별 예약번호 고유값, 원본 메일 ID 기반 이벤트 중복 방지, 일시와 상태 변경 이력. 원장 접근 통제, 데이터 보존기간, 개인정보 최소화, RLS 검증.
3. **예약 상세**: 네이버 공식 예약 파트너/API 권한을 먼저 문의. 네이버 정책상 허용되고 기술적으로 안정적인 자동 조회 방식만 허용. 로그인 세션 저장을 외부 서비스 운영자의 무제한 권한으로 간주하지 않는다.
4. **재원생 매칭**: 상세 질문의 학생 이름 및 학년·나이로 현재 재원생만 후보로 추린다. 동명이인이나 불일치는 수동 확인. 상담 완료 또는 종합 피드백을 예약 수신만으로 자동 처리하지 않는다.
5. **취소·변경**: 실제 이메일 샘플을 확보하고 상태 전이 테스트를 추가한다. 상담 기록을 삭제하지 않는다.
6. **PC·모바일 동일성**: 브라우저 로컬 저장과 무관한 서버 데이터 소스로 처리한다. 실데이터에 쓰기 전에 테스트 학원에서 검증한다.

네이버 공식 제휴·기술 API 문의: https://navercorp.com/company/partnership

이 단계가 성공해도 운영 자동 동기화가 완료된 상태는 아니다.


## 비비작 1개 학원 네이버 예약 상세 조회 파일럿 — 2026-10-24

원장 요청에 따라 여러 학원 연결 작업은 보류합니다. 네이버 예약 파트너센터의 승인된 TinyFish 브라우저 프로필을 재사용하는 코드를 별도 파일럿으로 만들었습니다.

- PC/모바일: 상담 예약 안내 → 네이버 상담 예약 (시험) 탭. 원장이 예약번호를 하나 입력하고 유료 조회를 명시적으로 승인할 때만 실행합니다.
- 서버: POST /api/naver-booking. 먼저 기존 Olli 원장 세션/현재 학원을 검사하고, 하나의 사전 지정된 academy_id만 허용합니다.
- 수집: 네이버 상세 우측 패널 예약자입력정보의 이름, (초등, 유치부 반) 학년 또는 나이. 예약번호·상품·시간·상태도 저장합니다. 이메일·전화번호 등은 가져오지 않습니다.
- 검사: 요청 예약번호와 네이버 사업 ID가 정확히 일치하고 상태가 confirmed이며 이름/나이 답변이 있을 때에만 저장합니다.
- 학생 연결: 같은 이름의 재원생 후보를 보여주되 자동 배정하지 않습니다. 원장이 직접 선택합니다. 명백한 나이·학년 불일치는 차단합니다. 기존 상담 완료/종합 피드백/알림톡 상태는 변경하지 않습니다.
- 중복 비용: 같은 예약을 30분 이내 반복 조회하면 저장된 결과를 재사용합니다. 자동 주기 조회를 설정하지 않았습니다.

### 운영 시작 전 필요한 비공개 설정

1. 검토용 SQL: supabase/migrations/20261024133000_naver_booking_pilot_reservations.sql 을 안전성 테스트 후 적용. 현재 실 DB에는 적용하지 않았습니다.
2. 서버 비밀 환경변수:
   - OLLI_NAVER_PILOT_ACADEMY_ID: 정확한 비비작아이성향미술학원 academy UUID.
   - OLLI_NAVER_PILOT_BUSINESS_ID: 승인된 네이버 예약 상세 주소의 /bizes/ ID.
   - OLLI_NAVER_PILOT_TINYFISH_PROFILE_ID: 승인된 TinyFish 저장 로그인 프로필 ID.
   - OLLI_NAVER_PILOT_TINYFISH_API_KEY: 해당 TinyFish 계정의 비공개 서버 API 키.
   - SUPABASE_SECRET_KEY: 기존 올리 서버 비밀키를 재사용.
   네이버 비밀번호·세션 쿠키를 앱이나 Git에 복사하지 않습니다.
3. 저장된 로그인 상태는 ChatGPT의 TinyFish 연결에서 성공했지만, 올리 배포 서버에 그 계정의 API 연결은 아직 설정하지 않았습니다. 따라서 현 단계에서는 운영 앱이 네이버를 자동으로 읽지 않습니다.
4. 네이버 예약 상세 화면 자동 조회의 서비스 정책·개인정보 처리 위탁 적합성을 확인합니다. 네이버 로그인은 공식 예약 상세 API 권한 승인이 아닙니다.
5. 테스트용 DB 및 원장 권한 검증, 네이버 실제 예약 1건의 이름·나이 정확도, 동명이인/재로그인/시간대 실패 처리 검증 후 병합·배포합니다.
6. TinyFish 조회는 사용량 과금되므로 수동 명령에서만 실행합니다. 예약번호를 메일에서 자동 수집하는 기능이나 예약 변경·취소 동기화는 아직 미구현입니다.

파일럿은 별도 예약 목록을 만들며 기존 상담 예정 계산/종합 피드백/학부모 알림톡 코드는 변경하지 않습니다.
